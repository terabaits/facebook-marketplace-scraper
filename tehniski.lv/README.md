# tehniski.lv

Latvian tech news portal.

## Dev
- Copy `.env.example` to `.env` and fill in
- `npm run db:migrate`
- `npm run db:seed`
- `npm run dev` → http://localhost:5002

## Test
- `npm test` (unit + integration via Vitest)
- `npm run test:e2e` (Playwright)
